ตั้งค่าสถานะระบบ (System Settings)

ปรับแต่งค่ากำหนดหลัก กฎการคำนวณคาร์บอน และเทมเพลตอีเมล

การตั้งค่าทั่วไป (General)
ปีที่ใช้เป็นมาตรฐานในการเปรียบเทียบการลดคาร์บอน
กฎการประมวลผลคาร์บอน (Carbon Rules)
kgCO2e
แจ้งเตือนหากองค์กรใช้เกินเกณฑ์ในเดือนนั้น
การเชื่อมต่อระบบชำระเงิน (Stripe Integration)
ใช้สำหรับระบบตัดบัตรเครดิตอัตโนมัติ คุณสามารถดู API Keys ได้จากหน้า Dashboard ของ Stripe
อีเมลเทมเพลต (Email Templates)
ชื่อเทมเพลต หัวข้ออีเมล (Subject) จัดการ
ระบบตอบรับการสมัครสมาชิก ยินดีต้อนรับสู่ GreenSync!
อีเมลแจ้งเตือนการรีเซ็ตรหัสผ่าน คำขอกำหนดรหัสผ่านใหม่ของคุณ
