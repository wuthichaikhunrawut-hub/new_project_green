2. รายการที่คงไว้ตามหลัก Zero-Bloat (⛔)

คงไว้เพื่อรักษาเสถียรภาพ

รายการต่อไปนี้เป็นข้อเสนอแนะสำหรับการขยายระบบในอนาคต แต่ถูก คงไว้ตามเดิม ในรอบการ Refactor นี้เพื่อป้องกันความเสี่ยงและหลีกเลี่ยงการเพิ่มโค้ดเกินจำเป็น (Zero Feature Bloat):

⛔ คงไว้
การเพิ่ม Webhook Signatures สำหรับระบบภายนอกอื่นที่ไม่ใช่ Stripe

Stripe Webhook Signature มีการตรวจสอบด้วย stripe.webhooks.constructEvent อยู่แล้ว จึงไม่มีความจำเป็นต้องเพิ่ม custom middleware สำหรับผู้ให้บริการอื่นที่ยังไม่มีการใช้งานจริง

⛔ คงไว้
การสร้าง Database Migrations ใหม่ทับ Initial Schema

ใช้ Dynamic Auto-create สำหรับตาราง system_settings เพื่อความเข้ากันได้ 100% กับฐานข้อมูลปัจจุบันและชุด Automated Tests ทั้งหมด โดยไม่ต้องรัน manual migration

⛔ คงไว้
ฟีเจอร์ Multi-Tenancy Subdomain Routing

ระบบปัจจุบันใช้ Header x-org-id ร่วมกับ JWT Claim ในการแยก Tenancy อย่างสมบูรณ์และปลอดภัยแล้ว จึงไม่เพิ่ม Subdomain DNS Resolver ที่ซ้ำซ้อน
