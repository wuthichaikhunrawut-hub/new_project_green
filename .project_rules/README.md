# กฎเกณฑ์และข้อกำหนดของโปรเจกต์ (Project Rules & Guidelines)

โฟลเดอร์ `.project_rules` นี้ถูกสร้างขึ้นมาเพื่อเก็บรวบรวม **กฎเกณฑ์ ข้อกำหนด ข้อจำกัด และมาตรฐานการทำงาน** ทั้งหมดของโปรเจกต์ **Green Sync** 

โฟลเดอร์นี้มีความสำคัญมาก เนื่องจาก AI Assistant (รวมถึงนักพัฒนาคนอื่นๆ ที่เข้ามาในโปรเจกต์) จะต้องเข้ามาอ่านและทำความเข้าใจข้อมูลในโฟลเดอร์นี้เป็น **อันดับแรกเสมอ** เพื่อให้การเขียนโค้ด การออกแบบ UI และการจัดการฐานข้อมูลเป็นไปในทิศทางเดียวกัน และไม่เกิดข้อผิดพลาดร้ายแรง

## ไฟล์สำคัญในโฟลเดอร์นี้

### 1. `SKILL.MD` (ไฟล์กฎเหล็ก)
ไฟล์นี้คือคู่มือหลักที่บรรจุบริบททั้งหมดของโปรเจกต์ (Project Context) ซึ่งครอบคลุมหัวข้อต่อไปนี้:
- **ภาพรวมโปรเจกต์**: ระบบบริหารจัดการ Green Office และ Sustainability 
- **Tech Stack**: 
  - Frontend: React, Next.js, TypeScript, TailwindCSS, shadcn/ui
  - Backend: Node.js, NestJS, PostgreSQL, TypeORM
- **แนวทางการออกแบบ (UI/UX)**: เน้นความ Modern, Premium, Eco-Tech (สีหลัก: Green, Emerald) โค้งมน โปร่งสบาย และลื่นไหล
- **กฎเกณฑ์ฐานข้อมูล (Database Rules)**: **ห้ามลบ Table อัตโนมัติ หรือทำลายข้อมูล (Destructive Migration)** เด็ดขาด ต้องวิเคราะห์ผลกระทบทุกครั้งเพื่อรักษาข้อมูลบน Production
- **มาตรฐานการเขียนโค้ด (Coding Standards)**: โค้ดต้อง Clean, Modular, ห้าม Hardcode, และคำนึงถึง Scalability เสมอ

## วิธีการใช้งานโฟลเดอร์นี้
1. **สำหรับ AI Assistant**: ให้อ่านไฟล์ `SKILL.MD` ทุกครั้งที่เริ่มการทำงาน เพื่อให้แน่ใจว่าการสร้างหรือแก้ไขโค้ดสอดคล้องกับข้อกำหนด
2. **สำหรับการเพิ่มข้อกำหนดใหม่**: หากมีข้อตกลง สถาปัตยกรรมใหม่ หรือโครงสร้างที่อยากให้ทุกคนและ AI ทำตาม ให้เพิ่มลงในไฟล์ `SKILL.MD` หรือสร้างไฟล์ `.md` ใหม่ในโฟลเดอร์นี้และลิงก์มาที่ README นี้
